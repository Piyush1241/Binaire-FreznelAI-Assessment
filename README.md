# Model Discovery Engine (FRZi-inference)

A web interface built with React, Vite, and TypeScript featuring an Adobe Spectrum HUD design aesthetic for interacting with and discovering model capabilities.

## Features

- **Model Discovery & Catalog**: Browse, search, and inspect available model benchmarks and configurations.
- **Spectrum HUD UI**: Modern dark theme layout with dynamic visual components built with React and Framer Motion.
- **Real-Time Data Integration**: Firebase integration for dynamic model updates and settings sync.

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm 

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Piyush1241/Binaire-FreznelAI-Assessment.git
   cd Binaire-FreznelAI-Assessment
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

### Development

Run the local development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application in your browser.

### Build

Build the project for production:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Tech Stack

- Frontend Framework: React 18 + TypeScript
- Build Tool: Vite
- Icons & Motion: Lucide React, Framer Motion
- Backend Services: Firebase
